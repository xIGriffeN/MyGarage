JIGGY 1.9.4 - JIGGY Cloud connected

Public profiles now use the self-hosted JIGGY Cloud API:
https://api.jiggy-cloud.org

Public profile frontend:
https://xigriffen.github.io/MyGarage/?id=<PROFILE-ID>

Supabase legacy setup files were removed from this repo-ready package.
No Cloud URL, API key or Supabase configuration is required by end users.

Required server state:
- JIGGY API reachable through Cloudflare Tunnel
- CORS enabled
- GET/POST/PUT/DELETE /api/profiles endpoints available

GitHub Pages deploys the public-profile directory via .github/workflows/pages.yml.
